# A1 mini と TeQiller A1 Plotter Module の校正

校正はプリンター固有の実測です。初期JSONの `draw_z=5`、`pen_offset_y=0` などは仮の入力欄であり、推奨実測値ではありません。Web上の他人の校正値をコピーしないでください。

## 座標の約束

- 全てmm。機械座標はノズルの位置、Xは右、Yはベッド奥方向。
- `pen_offset_x/y = ペン先の座標 − ノズルの座標`。ペンがノズルより前側ならYオフセットは負。
- `paper_x/y` は、紙の左下（手前左）の機械座標。`paper_width/height` は紙の実寸。ページ上端は `paper_y + paper_height`。
- PDFは左上原点なので、出力時は次で変換する。

```text
nozzle_x = paper_x + page_x - pen_offset_x
nozzle_y = paper_y + paper_height - page_y - pen_offset_y
```

- `draw_z` は紙に正常に書ける **ノズルZ表示値**。ペン先をノズルより4mm下へ出したことを、`draw_z=4` と読み替えない。紙の厚みやスプリングの押込みで変わる。
- `lift_z` は紙から離れるZ、`safe_z` は開始・終了時の退避Z。

## 初回の手順

1. プリンターを停止し、ペンを外す。純正カバーから取り付け部へ交換した状態で、モジュールが確実に固定されていることを確認する。
2. **ペンなしで**プリンター本体のホーム操作を行う。ホームが終わり、座標が確定している状態を維持する。
3. Zを十分上げる。最初は15〜20mm程度の表示位置から、実際にペン先・ノズル・紙に間隔があることを確認する。移動中はペンを挿さない。
4. 平らな紙を固定する。標準は148×148mm。余白部分を薄いテープで固定し、XY可動範囲へクリップや段差を作らない。紙の左下位置を測り `paper_x/y` へ入力する。
5. 停止した状態でペンを装着する。モデル説明ではペン先をノズルより約4mm下に出す。スプリングの可動を残し、紙に押しつけた状態で固定しない。
6. 本体画面でノズルを安全な中央付近へ移し、紙から離れた状態でノズル表示XYとペン先の実際のXYを測る。その差を `pen_offset_x/y` に入れる。移動前にはZの余裕を確認する。
7. ペン先が紙へ近づくまで慎重にZを下げ、近づいたら最小刻みで調整する。紙に軽く触れ、スプリングが過度に縮まない位置を `draw_z` にする。接触後にXYを動かして試す場合は、ごく短い距離と低速から始める。
8. Zを上げてペンが完全に離れた値を `lift_z` にする。ソフトは `lift_z - draw_z >= 0.5mm` を要求する。さらに余裕のある `safe_z` を測る。ソフトで許可する範囲は `1 <= draw_z < lift_z <= safe_z <= 30mm`。
9. ペン・ホルダー・紙固定具・ケーブルが干渉しないノズルXY範囲を確認し、`nozzle_min/max_x/y` に入れる。初期値5〜175mmも保証値ではない。端を確認するときもZを上げる。ノズルとペン先の範囲は別に考える。
10. 最初の速度は描画1200mm/min（20mm/s）、空中移動3000mm/min（50mm/s）、Z300mm/min（5mm/s）の入力例。ペンの揺れや紙の状態に応じて低くする。ペン先の実線幅を `pen_width` に入力する。
11. 全て実測したら `calibration_notes` にペン、紙、取り付け状態、日付を記録し、`calibrated: true` にする。これはソフトの自動検出ではなく、作業者の実測記録。

ペンを装着したまま再ホームしない。位置が失われた場合は、ペンを外して手順2からやり直す。

## 校正パターンと空描き

```sh
./plotnote profile show my-a1-mini.json
./plotnote calibration --profile my-a1-mini.json -o calibration-preview
./plotnote export calibration-preview/page-001.svg --profile my-a1-mini.json --homed --air-mm 5 -o calibration-air
```

パターンには描画領域の内側の枠、20×20mmの正方形、中心十字を含む。空描きでは全てのZに5mm加算する。出力後の `effective-profile.json` がその実行に使った高さになる。

ペンを高く保持するか外した状態で、実際に紙の上の意図した位置を動くこと、ペン上下の順番、枠の干渉がないことを確認する。次に元の実測値へペンを戻し、`--air-mm` を付けずに小さなパターンを書いて確認する。

20mm正方形が実測20mmで、文字の横線・縦線が途切れず、空中移動で紙を引っかかないことを確認してから本番ノートに進む。

## ファイルの実行

- 1ページ1ジョブ。最初は監視しながら、小さな校正パターンから始める。
- `.gcode` の直接実行、またはBambu用 `.gcode.3mf` の読み込みを使用する。機種はA1 mini。再スライス、通常印刷の開始G-code追加、MakerWorldのA1専用開始コード貼付けはしない。
- 起動時にホーミング、自動レベリング、振動校正、パージなどが走る経路では、低い位置にペンを装着したまま実行しない。使用するファームウェアと送信方法の動作を確認する。本ソフトはプリンター状態を通信で検出しない。
- 生成G-codeのヒーター指定はOFFのみ。ただしジョブ開始時にファームウェアが独自に行う予熱等を本ソフトから保証することはできない。
- 終了時は現在XYのまま `safe_z` へ上がる。ペンや紙を扱う前に停止を確認し、通常の3D印刷やホーム操作へ戻る前にペンを外す。
- 紙を替えるときも同じ左下位置・向き・厚みに合わせる。ペン交換、取り付け変更、紙厚変更では再校正する。

## よくある症状

| 症状 | 確認するもの |
|---|---|
| 全体が前後へずれる | Yオフセットの符号、紙の左下、PDFの上下反転 |
| 範囲外エラー | `profile show` の描画矩形、オフセット、紙位置。自動縮小で隠さない |
| 線が途切れる | 紙の平面性、スプリング、実測draw_z、速度 |
| 空中移動で線が出る | lift_zと紙の厚さ。ペンを外して退避後に再調整 |
| 数式が別の文字になる | 元PDFのUnicode抽出とフォント。特殊フォントの符号位置を使わない |
| ソフトが校正済みでないと止める | 実測を完了してからcalibratedをtrueにする |

実機試験はこのソフト開発環境では実施していない。ファイル内の幾何・筆順・命令検査と、物理的な校正・動作確認は分けて記録する。
