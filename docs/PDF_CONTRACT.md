# PlotNoteへ渡すPDFの作成条件

## 1. ページ寸法と向き

- 標準テンプレートは **横148.000 mm × 縦148.000 mm**。PDFのページそのものをこの寸法にする。A4の中央へ148mmの枠を置く方法は不可。
- 別寸法も扱えるが、縦・横とも180mm以下で、校正プロファイルの `paper_width` / `paper_height` と **0.01 mm以内**で一致させる。
- A6は横105 × 縦148 mm。横向きなら横148 × 縦105 mmとして、プロファイルも同じ寸法にする。A5は148 × 210 mmなので、そのままでは不可。
- 自動縮小、自動回転、タイル分割はしない。異なるサイズを混ぜたPDFは、各サイズに合うプロファイルで分けて出力する。
- PDFの90度単位のページ回転には対応する。ただし管理しやすいよう、作成時は回転0で実際の縦横を指定することを推奨。
- ページ原点は左上、Xは右、Yは下。単位はmm。PDF内部のptへは `pt = mm × 72 / 25.4` で変換する。148mmは419.527559pt。

## 2. 実際に書ける場所と余白

最初の原稿は上下左右 **12 mm以上**の余白を取る。ただしこれは全ての取り付け状態で描画可能なことを保証する数値ではない。校正後、次を実行して **reachable_page_rect_mm** を確認する。

```sh
./plotnote profile show my-a1-mini.json
```

結果は `[左, 上, 右, 下]` のmm座標。全てのペン軌跡をこの範囲に入れ、さらに紙端からペン幅の半分以上離す。ソフトは実際の各点を検査するので、範囲外なら出力できない。ペン先の位置差を解消するために原稿を手動で適当にずらす必要はない。

固定用テープやクリップ、紙の段差、ノートの背表紙を描画範囲へ置かない。厚い綴じノートは、平らな単票と同じ校正では使えない。

## 3. 文字

- 文字はUnicodeを抽出できるPDFテキストとして保存する。文字を画像化・アウトライン化しない。必要な文字を含むフォントを使い、PDFへ埋め込む。
- ソフトは文字の基準位置・文字送り・向きを読み、筆順付き字体へ置き換える。元のフォントの外観、太字、装飾、筆圧の変化は維持しない。
- 本文の推奨emサイズは **3.5〜4 mm（約10〜11.3pt）**。見出しは5mm前後（約14pt）。実際の字面は書体によりemより小さい。
- 添字などは **2mm（約5.7pt）以上**を目安にする。2mm未満には警告が出る。細いペンでも複雑な漢字は大きめにする。
- 行送りは本文サイズの **1.5倍以上**を推奨。上下の線や図形との間にも余白を置く。
- 横書き、90度回転などの文字方向に対応。縦書きの組版、文字クリップ、透明文字、複雑な変形は使わない。
- ASCIIには英数字向けフォント、日本語には日本語フォントを使うと読みやすい。全角幅で英字を組むと、ストローク字体でも字間はそのまま広くなる。
- 対応一覧は `plotnote fonts --list`、個別検査は `plotnote fonts --check '使用予定文字列'`。外字、絵文字、任意のUnicode全域には対応しない。未対応文字はページ・座標・U+コード付きでエラーになる。

## 4. 数式

- 数式は「文字」と「線」で作る。分数線・根号の横棒・行列括弧などはベクター線にする。分子・分母・添字はそれぞれの位置へPDFテキストで配置する。
- LaTeXを使う場合も、生成されたPDFで記号を正しいUnicodeとして抽出できることを確認する。記号が独自フォントの文字番号へ置き換わる出力や、数式全体のアウトライン化は不可。
- `α β γ …` などのギリシャ文字、`− × ÷ ± ≤ ≥ ≠ ≈ ∞ ∑ ∏ ∫ ∂ √ ∈ ∉ ∅ ∇ ∀ ∃ ∝ → ← ↔ ⇒ ⇔ ↑ ↓ ⋅ ° ′ ″ ℓ ℏ`、ASCIIの演算子・括弧に対応。
- Unicodeの上付き・下付き数字・一部の英字に対応。より自由な添字は、通常の文字を小さいフォントサイズで上下へ配置する。
- 数式パッケージが生成した特殊記号を無条件には扱えない。必ず `inspect` とプレビューで検査する。

## 5. 図・グラフ・表

- SVGをPDFへ埋め込むとき、PNGへ変換せずベクターのまま埋め込む。
- 直線、折れ線、ベジェ曲線、円、楕円、枠線を使用する。図形は **fill="none"**、明確なstrokeを持たせる。
- 曲線は0.025mmの許容誤差で折れ線化する。寸法・アスペクト比は維持する。
- グラフの軸名・凡例・目盛り文字もPDFテキストで保持する。Matplotlibなら `pdf.fonttype = 42` を指定し、出力後にUnicode抽出できるか検査する。
- 図形の長方形クリッピングに対応。円形・複雑なクリップ、マスク、フィルター、グラデーション、透明度は使用しない。
- 破線は短い独立した実線へ展開する。SVG markerで作った矢印は普通の線へ展開する。外部参照画像・フォント・スクリプトは使わない。
- 1本のペンなので、色分けや線幅の違いは再現しない。実際の線幅は設定したペン幅。線間隔は **ペン幅の2倍以上**を目安にする。線幅0.3mmなら0.6mm以上。
- 黒丸などの塗りつぶし記号が必要なら、明示的な小さな円や中心線の記号に置き換える。塗り領域から中心線を推測する処理は行わない。

## 6. 使わないもの

写真、ラスター画像、スキャンPDF、アウトライン文字、影、塗りつぶし領域、白い図形による隠蔽、注釈・フォーム、パスワード保護。画像があっても黙って無視せず、変換を停止する。

PDF作成ソフト側で既に文字が空白や別の文字へ化けている場合、元の意図までは復元できない。入力PDF自体を目視し、Unicode抽出結果も確認する。
