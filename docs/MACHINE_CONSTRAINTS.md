# 所有者の A1 mini に固定する条件

この文書は **今回の所有者の A1 mini とペンホルダー** の条件。A1 や別の A1 mini の一般推奨値ではない。友人側の Agent は、この装置用のファイルを生成する。ファイルを収めるための機械設定変更は行わない。

## 1. 紙とタイル

| 項目 | 固定値・運用 |
|---|---|
| 機種 | Bambu Lab A1 mini。Bambu コンテナの機種識別子は `N1` |
| プレート | 180 × 180 mm |
| 紙 | A4 縦、210 × 297 mm。長辺を機械 Y 方向へ置く |
| 横位置 | 紙をプレートの左右中央へ。左右へ約 15 mm ずつはみ出す |
| 1 回の描画窓 | 横 165 × 縦 127.5 mm |
| A4 内の窓の X | 紙の左端から 22.5 mm |
| 1 回目の窓の上端 | A4 の上端から 36.5 mm |
| 2 回目の窓の上端 | A4 の上端から 164.5 mm |
| 1 回目の置き方 | 紙の上端をプレートの奥端に合わせる |
| 2 回目の置き方 | 紙の下端をプレートの手前端に合わせる |
| 両面の順序 | 面1・1回目 → 面1・2回目 → 面2・1回目 → 面2・2回目 |
| 裏返し | 上端を上のまま、通常のページをめくる向き。裏面も横は中央 |

A4 **1 面は 2 タイル、両面 1 枚は 4 ジョブ**。紙の枚数、A4 の面数、実機ジョブ数を同じ意味で「ページ」と呼ばない。

1 回目の窓は 36.5〜164.0 mm、2 回目は 164.5〜292.0 mm。間に 0.5 mm の区切りがある。紙の上部約 36 mm と下部約 5 mm は書かない。1 文字や 1 本の数式をタイルの境界にまたがせない。紙を上下で約 1 mm ずらすと、継ぎ目の行間も変わる。

横方向の窓は A4 内で 22.5〜187.5 mm。プレート上では 7.5〜172.5 mm に相当する。窓の端まで文字を詰める許可ではない。実際の線の全点、ペン幅、図のはみ出しを検査する。

## 2. 座標

機械座標は **ノズルの位置**。X は右、Y は奥、Z は上。プレビューの原点は紙/タイルの左上で、下へ Y が増える。

| 項目 | 値 |
|---|---:|
| `pen_offset_x` | 0 mm |
| `pen_offset_y` | -30.8 mm |
| `paper_x` | 7.5 mm |
| 1 回目の `paper_y` | 16.0 mm |
| 2 回目の `paper_y` | 5.0 mm |
| `paper_width` | 165.0 mm |
| `paper_height` | 127.5 mm |
| 生成時ノズル XY の許可範囲 | X/Y とも 5.0〜175.0 mm |

`paper_x/y` は、ここでは A4 全体ではなく **現在描く窓の左下**。A4 の紙幅 210 mm をそのままタイル用プロファイルへ設定しない。

```text
pen_offset = ペン先の位置 - ノズルの位置
nozzle_x = paper_x + tile_x - pen_offset_x
nozzle_y = paper_y + paper_height - tile_y - pen_offset_y

A4_preview_x = tile_x + 22.5
A4_preview_y = tile_y + (36.5 または 164.5)
```

ペンはノズルより 30.8 mm 手前にある。したがって、ノズルが奥の Y=175 まで行っても、ペン先は Y=144.2。紙の上端をプレート奥端 Y=180 に合わせた場合、上端から 35.8 mm は届かない。これが上余白を確保する理由。

`G90` は絶対座標の指定であり、原点の物理的位置を確定する命令ではない。ホーム未確定の状態で `X14` を送ると、今回の実機では中央付近に留まった。中央を原点だと推測して座標を -90 mm する解決は行わない。

## 3. 高さと速度

| 項目 | 今回の値 | 意味 |
|---|---:|---|
| 取り付け基準 | Z=5.0 mm | ペンなしで位置合わせ後、ペン先を紙に軽く触れさせて固定する基準 |
| `draw_z` | 4.8 mm | 筆記位置。以前の 4.9 から 0.1 mm 下げて、わずかに筆圧を増した |
| `lift_z` | 6.5 mm | ストローク間のペン上げ |
| `safe_z` | 10.0 mm | 本番ジョブ開始・終了時の退避 |
| 位置合わせ中の退避 | Z=15 mm | ペンなしで XY を移動するための高さ。取り付け基準とは別 |
| `draw_feed` | 1800 mm/min | 30 mm/s |
| `travel_feed` | 2400 mm/min | 40 mm/s |
| `z_feed` | 600 mm/min | 本番 G-code の Z 速度、10 mm/s |
| ペン幅 | 0.3 mm | プレビューと検査の設定値 |

この値は Z5 でペンを取り付ける運用と一組。Z15 で適当にペンを挿して同じ G-code を走らせると、高さが合う保証はない。Z はノズル表示値であり、ペンの突き出し寸法ではない。ペン、紙厚、ホルダーを変えた場合は所有者が校正する。

筆圧を濃くする依頼に対して、今回の変更は描画 Z だけ -0.1 mm。上げ高さ、XY、文字の間隔は変更していない。友人の Agent がさらに Z を下げたり速度を上げたりしない。

## 4. 本番ファイルに含める動作

生成器の許可命令は `G21`, `G90`, `G1`, `M104 S0`, `M140 S0`, `M106 S0`, `M400`。本番ファイルは、ペンを上げ、位置へ移動し、筆記 Z へ下げ、線を書き、上げる。最後は現在 XY のまま `safe_z` へ上がる。

ホーム `G28`、座標書き換え `G92`、相対移動 `G91`、押出 E、正温度の加熱、レベリング、パージ、ノズル拭き、通常の 3D 印刷マクロは本番ファイルに入れない。所有者のホーム・取り付け用スクリプトは **別の実機準備プログラム** であり、印刷ファイルの許可命令を広げる根拠にならない。

`.gcode.3mf` は既存ツールパスを格納するコンテナ。再スライスする 3D モデルではない。収容 G-code と単体 `.gcode` を照合し、MD5 および納品用チェックサムを検査する。

## 5. 実機状態の必須条件と観測の限界

所有者が開始する直前に、最新の状態報告で次を確認する。

- 対象が A1 mini で、実行中の別ジョブがない。
- `print_error` が 0、HMS 診断が空、ノズル/ベッドの目標温度が 0。
- `home_flag` が整数で、`home_flag & 7 == 7`。下位 3 bit は X/Y/Z のホーム状態。

今回の記録では `847070608 & 7 == 0` が未確定、`847070615 & 7 == 7` が全軸ホーム済みだった。**大きな整数全体を固定値として比較しない**。欠落・0・部分ホームを、ホーム済みとして扱わない。

通信の ACK は命令の受信確認で、物理的位置やペンの接触をカメラ/実測で確認したことにはならない。M114 は受信 ACK が返ったが、実座標は返らなかった。静的 G-code 検査も、紙の固定や干渉が安全であることまでは検証しない。

生成で許可する 5〜175 mm の矩形全体について、ホルダー・固定具を含む網羅的な実機校正が完了したという証拠はない。古い実測範囲は X/Y 約40〜150 mm、今回の v4 では Y 約172 mm までのデータを実行した。成功したノートと、全範囲の安全確認を区別する。

## 6. 本体が付け加えた動作

本番 G-code は加熱 OFF のみでも、今回のファームウェアは開始時にノズル目標約75℃、一時停止時に約90℃を設定した。開始後は生成コードによって目標0へ戻ることを観測した。したがって「ファイルに加熱がないので本体も加熱しない」と説明しない。

一時停止の90℃を監視プログラムが異常として検知し、STOP を送ってジョブをキャンセルした実例がある。その結果、ホーム状態も失われた。**通常キャンセル・一時停止・監視処理でホームを必ず保持できるとは約束しない**。再開前は実機状態を再確認する。
