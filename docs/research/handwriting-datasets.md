- **ETLの公式ページは、この環境からも取得エージェントからも接続を切られ（ECONNRESET）、本文を読めなかった。** 以下は検索結果の記述で、公式の原文では未確認:

  - 第三者の記述に「非商用に限る」という説明がある。公式の文言と食い違う可能性があるため、利用前に公式の最新規約を直接確認すること。
  - 登録が必要という点も、第三者の記述に基づく。
  - ETL1・ETL6・ETL7の収録内容・件数・画像サイズは未確認。
- **HANDS-Kondateの規約（公式ページで確認）**: 学術価格でも教育・研究目的のみ、商用不可。第三者への配布は禁止。購入パッケージを開封した時点で規約に同意したとみなされる。

## EMNIST の実測（✅）

保存先: `output/datasets/emnist-byclass/`（各ファイルの SHA-256 は `SHA256SUMS`）。ファイルの大きさは公開値と一致し、件数は 697,932 + 116,323 = 814,255 で公表値と一致。

- 小さな CNN（`scripts/train_emnist_cnn.py`、3エポック、約4分、Apple GPU）で、公式テスト精度は **86.5%**。この分類の通常の上限（約87〜88%）に近い。大文字と小文字の区別が主な誤りの原因。
- 重み: `output/datasets/cnn62.pt`。
- **本人の確認済み英数字49件**（ペンの軌跡から描画）: 完全一致 73.5%、大文字小文字を無視 83.7%、**上位3候補に正解が入る割合 93.9%**。外れは O/0、l/1、c/C、s/S など人間でも紛らわしい組み合わせ。件数が少ないため、数値には幅がある。
- **未確認の英数字565件**: 上位3候補にラベルが入る割合は約50%（大文字小文字を無視で56%）。確認済みの94%と大きく差があり、残りの約半分は仮ラベルの誤りか切り出し不良の可能性が高い。
- 結果: `output/personal-font/lt8/emnist_alnum_evidence.json`（証拠のみ。承認はしていない。DBは読み取り専用で開いた）。再実行は `scripts/emnist_apply.py`（torch が入った Python で実行）。

## 使い道の整理

| 対象 | 方法 | 状況 |
|---|---|---|
| 英字・数字（565件） | EMNISTの分類器で上位3候補に入るものを確認候補にする | 証拠を作成済み |
| ひらがな・カタカナ・第1水準漢字 | LT8（ETL系で学習済み）。さらに本人の確認済み見本で個人適応すれば精度向上の余地あり | LT8は実行済み |
| 小書きかな・濁点付きカタカナ・記号・第2水準以降の漢字 | 公開データなし | 別の手段（外部OCRなど）が必要 |
| ペン軌跡の学習（将来） | Kuchibue（申請して購入） | 未入手 |
