## 実際に書くまで

1. 試作用に**148×148mmの平らな紙**を用意します。まず1枚だけで十分です。本文が潰れる場合は細いペンへ替えるか、原稿を大きい文字に作り直します。
2. ペンなしで本体をホーム位置へ戻し、Zを上げてからペンを装着します。ペンを低く装着したまま再ホームしません。
3. [校正手順](../../docs/CALIBRATION.md)で、紙の左下位置、ペン先とノズルのXY差、紙に触れるノズルZ、ペンが離れるZ、安全なXY範囲を実測します。`printer-profile-measure-first.json` を別名で保存し、値を記入します。全項目を実測してから `calibrated` を `true` にします。
4. 下のコマンドで **試し書きページの空描き**を作ります。Zが実測値より5mm高いデータになります。
5. 空描きで位置と干渉を確認したら、`test-contact` で実際に文字サイズ見本を書きます。20mm正方形が実寸で、ペン上げ時に線が出ず、2.8mmの漢字が読めることを確認します。
6. 最後に `notes-contact` で4ページを書き出します。ページごとに紙を同じ位置へ置き直し、手動で実行します。

以下は `PlotNote` フォルダをカレントディレクトリにして実行します。`measured.json` は実測後のプロファイルです。

```sh
.venv/bin/python output/exam-note/prepare_gcode.py --profile measured.json --stage test-air --homed -o output/exam-note/test-air
.venv/bin/python output/exam-note/prepare_gcode.py --profile measured.json --stage test-contact --homed -o output/exam-note/test-contact
.venv/bin/python output/exam-note/prepare_gcode.py --profile measured.json --stage notes-contact --homed -o output/exam-note/notes-contact
```

出力はページごとの `.gcode` と `.gcode.3mf`、検査結果、実行に用いたプロファイルです。プリンターへ自動送信しません。Bambu Studioで再スライスしたり、通常印刷用やMakerWorldのA1専用の開始G-codeを足したりしないでください。

## 元メモから整理した点

- 血液型を質的データとして明示。量的な離散データの例は人数・回数にしました。
- 学生A/B/Cは識別用のID、観測変数は身長・睡眠時間・血液型の3項目として整理しました。
- 切れていた尺度の図を、分類・順序・差・比の比較表へ再構成しました。満足度は元画像の1〜5を保持しています。
- 不偏分散の平方根は、それ自体が母標準偏差の不偏推定量ではない点を補足しました。授業で「不偏標準偏差」と呼ぶ場合でも、式と推定の性質を区別してください。
- CVは正の平均を持つ適切な比率尺度で使うこと、Zは標準偏差0で定義できないこと、IQVではK>1・割合の和1が必要なことを追記しました。
- 式中のΣは、平均・分散等ではi=1〜n、IQVではk=1〜Kです。略記により小さい添字が増えすぎないようにしました。

補足確認：[内閣府 Society 5.0](https://www8.cao.go.jp/cstp/society5_0/)、[NIST 散らばりの尺度](https://www.itl.nist.gov/div898/handbook/eda/section3/eda356.htm)、[NumPy 標準偏差と不偏性](https://numpy.org/doc/stable/reference/generated/numpy.nanstd.html)。元の数学的定義と例を優先し、これらは誤解しやすい点の確認に使っています。
