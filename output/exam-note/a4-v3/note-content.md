分析設計
分析設計とはデータを使って問題を解決するために、何を、どのように分析し、その
結果をどう活用するかを設計すること
(1) 目的の設定:何を解決したいのか (2) データの収集・加工:必要なデータを
集め、分析できる状態にする (3) 手法の選択:どの統計・分析手法を使うか決め
る (4) 活用:分析結果を意思決定に使う
ビジネスでの使い方
a. 仮説検証:仮説を立て、その仮説が正しいか検証すること。例えば、YouT
ubeで「サムネイルを変更すると再生数が増えるのではないか」という仮説を立
て、実際のデータで確認
b. 知識発見:データの中から、経験則や意思決定に役立つ洞察を見つけること。
c. 原因究明:変化が起きたとき、その原因となる事象を解明すること。ランダム化比
較試験 対象をランダムに2つ以上のグループに分けて、異なる実験を行って結
果を比較 (相関だけでは因果を断定できない)
d. 判断支援:a〜cで得られた知見をもとに、人間の意思決定を支援すること。
e. 計画策定:中長期の計画を策定すること。例えば、販売データをもとに、来年の
生産計画やキャンペーンを計画すること
f. 活動代替:単純作業やパターンが決まっている作業を機械で自動化し、全体
の効率を向上させること。
g. 仮説検証サイクル(PDCA):plan do check action

ビッグデータとデータエンジニアリング
データサイエンス:情報工学・統計学・専門分野の知識を組み合わせ、データの価値を見出し、
意思決定の根拠を引き出す学問分野。 データエンジニアリング:大量のデータを管理し、分
析可能な形に変換する技術や仕組み。→ データサイエンスの前段階。
ICT:情報通信技術。ネットワークなどの通信技術を活用して情報を活用する技術の
総称。→ 大量のデータ(ビッグデータ)が取得可能に。
ビッグデータの特徴【3V】Volume(量)・Variety(多様性)・Velocity(速度)
【5V＝3V＋以下の2つ】Veracity(正確さ)・Value(価値)
収集方法 クローリング:インターネットを自動巡回して情報収集(広く浅く)。 スクレイピング:得
られた情報から必要なデータを抽出。 オープンデータ:インターネット上で公開されているデ
ータ。→ EBPM:証拠に基づく政策決定。
データガバナンス 企業や組織が保有するデータを安全に効果的に活用するための仕組
みやルール。 正確なデータを維持する。個人情報を安全に管理する。データ管理の責任を明
確にする。組織内でルールを統一する。目的:価値の最大化・リスクの最小化。
構造化データ:表形式(行・列)、検索・集計が容易。→ 関係データベース(RDB)で管
理。 非構造化データ:形式が決まっていない。例:画像、動画、音、文章、SNS投稿。
IoT:モノのインターネット化。 IoE:全てのもののインターネット化(人・データ・サービスも含む)。
IoA:能力のインターネット化。
データ収集と加工
データの収集 自分でデータを作る:アンケート・実験・観察。 他人のデータを使う:公開データ・ス
クレイピング・Webクローラー。 サンプリング:全体から一部を抽出し、分析対象を偏りなく選
ぶ。
データの問題 → データクレンジングによって処理する。 欠損値:あるべきデータが記録さ
れていない。→ 削除・補完。 異常値:現実に起こり得ない値。→ 修正・削除。 外れ値:
統計的に他の値から大きく外れた値。→ 除外・保持を判断。
外れ値の検出 IQR: 下限 = Q1 - 1.5 × IQR 上限 = Q3 + 1.5 × IQR 標準
偏差(±3σ): 下限 = 平均 - 3σ 上限 = 平均 + 3σ → 範囲外を外れ値(
の候補)とする。
バイアス 母集団を正しく反映していない偏り。サンプリングバイアス:標本抽出の偏り。 選
択バイアス:対象の選択による偏り。 測定バイアス:測定方法による偏り。対策:幅広い属
性を含めたデータの収集。公平性・代表性を意識する。
データクレンジング:データの問題を処理して分析可能な状態に整える。 アノテーション:補足
情報や説明を加える。 結合処理:共通するキーを用いて複数のデータを結合する。→ 
キーの不一致・重複データに注意。
データ表現
数値:整数・実数など。 文字:文字コードで表現。 画像:ピクセルごとの数値表現。 音声:波
形を数値化。 1 byte = 8 bit n bit = 2^n 通りの表現が可能。 2^10 = 1,0
24 2^20 = 1,048,576
文字 → 文字コード → バイト列 符号化:文字を数値(2進数)に変換すること。 ASC
II:英数字・記号(A=65、B=66)。 JIS X 0208:日本語。 Unicode:国際的な文字
コード規格。 Shift-JIS、UTF-8、UTF-16、UTF-32。
数理最適化と意思決定
数理最適化:制約条件の中で目的関数を最小化または最大化する方法。→ 最適な意
思決定。 目的関数:最適化したいことに関する関数。 決定変数:目的関数への入力変数。
制約条件:守らなければならない条件。 連続最適化問題:決定変数が実数値を取り、
連続的に変化可能。 離散最適化問題:解候補が離散的。代表例:組合せ最適化問
題。
